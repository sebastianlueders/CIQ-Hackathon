# Four-person ownership

1. UI/integration: apps/web, API routes, end-to-end tests.
2. Runtime: hardware discovery, model loading, inference, adapters.
3. Learning: consented datasets, teacher, training, evaluation.
4. Platform: Fuzzball bridge, artifacts, scheduling, job recovery.

Use separate worktrees. Integrate every 1–2 hours.
One owner controls shared contracts and dependency locks.

Milestones:
1. Real inference and a tiny Fuzzball workflow.
2. Prompt-only skill creation and feedback.
3. Real candidate training and held-out evaluation.
4. Publish/rollback and isolation checks.
5. Benchmark and rehearse.
