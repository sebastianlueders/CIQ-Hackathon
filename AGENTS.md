# Coding rules

- Read docs/ARCHITECTURE.md before implementing features.
- Edit only assigned paths; coordinate shared contract changes.
- Never overwrite published adapters in place.
- Pin inference requests to immutable skill versions.
- Keep training data separate from held-out evaluation data.
- Never commit credentials or send private traces without consent.
- Do not provision infrastructure or spend money automatically.
- Report tests actually run; do not present mocks as live integrations.
